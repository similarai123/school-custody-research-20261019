M1｜口径统一与政策底座

调研日期：2026 年 10 月 调研人：行业口径与政策研究员 适用项目：民办初高中段整校委托管理 + 教学运营输出商业可行性尽调

0. 口径声明（先读这一段）

为避免后续 M2–M7 模块互相打架，本模块所有"规模/校数/收入"数字一律按以下五维度拆分，禁止跨维度直接比较：

维度 拆分项 本模块采用的口径
a) 阶段 签约 / 已运营 以首年开学为"已运营"门槛；签约未开学计"已签约"
b) 权属 自营（举办者） / 托管（受托管理） 主办方持有办学许可证 = 自营；不持证仅受托 = 托管
c) 形态 管理输出（派驻团队） / 特许经营（品牌授权） 是否派驻校长/管理团队、是否签派驻人员劳动合同
d) 颗粒 学校数 / 学段数 一所完全中学（初高中合一）= 1 校，但 = 2 学段；按合同标的拆分
e) 深度 产品销售（系统/课程） / 整校交付（人员+管理） 是否派驻团队接管日常运营

对"托管"红线的判定（来自实施条例第十三条第四款 + 司法实践）：

合法托管：举办者保留"四个核心权"——办学许可证持有、法定代表人/理事长任命、印章与对公账户、年度预算审批； 非法托管（=变相出租出借办学许可证）：上述任一项实质性让渡给受托方。

1. 任务一：规模口径定义表

1.1 全项目统一规模口径定义表

维度 操作定义 判别要点（Yes 即落入此项） 常见误用（须警惕）
学校数 vs 学段数 一所含初高中的"完全中学"或"十二年一贯制"，学校数 = 1；学段数按合同标的拆分（高中部 = 1 学段；初中部 = 1 学段） 学校数：法人主体数；学段数：合同中明确受托方负责的学段 把"33 所自营高中"误称为"33 所学校"——含高中+初中或十二年一贯制时口径需说明；天立国际控股 FY2023 披露"自营高中 33 所"是学段口径，对应法人主体数明显小于 33
自营 vs 托管 自营：办学许可证持有方即为该集团/举办者；托管：受托方仅提供管理服务，办学许可证仍属原举办者 自营：合并报表 / 列入"自营学校"披露；托管：合同关系、收"管理费/托管费" "我们运营 N 所学校"未说明权属时一律追问；母公司持股≠自营，需穿透到办学许可证法人
签约 vs 已运营 签约：合同生效即计入；已运营：首批学生入学开学即计入；未通过筹设审批的不计入任何口径 签约=合同或协议文本生效；已运营=最近学年有实际招生并开学 集团宣传"覆盖 200+ 所学校"=签约口径（含待筹建）；新闻稿中"开学"才是已运营
管理输出 vs 特许经营/品牌授权 管理输出：受托方派驻校长/中层/骨干教师，签劳动合同（或事实劳动关系）归属受托方，受托方收管理费；特许/品牌授权：受托方只授权品牌名+课程体系，派驻极少或不派驻，受托方收品牌许可费/课程费 管理输出：派驻 ≥ 3 人（含校长），受托方发薪；特许：仅品牌名+教材+年度督导 把"加盟校""挂牌校""联盟校"统统归入"管理输出"是常见夸大；连平案例、青鸟同文对连平中学属于"管理输出"；衡水+长水的早期模式偏向"特许+管理组合"
整校交付 vs 产品销售 整校交付：派驻团队接管学校日常（教学+德育+行政+后勤之一项以上）；产品销售：仅卖 SaaS/课程/教材/师训 整校交付：合同标的含"派驻管理团队""输出管理体系"；产品销售：合同标的为"采购课程/系统/服务" "服务 X 所学校"未说明是卖课还是派驻——同一家公司同一数字可包含两种模式，需分母拆开

1.2 关键判别三道关（实务口径）

  1. 核心控制权是否保留（最高位判别）：

    • 办学许可证、年检、法定代表人、印章、对公账户、年度预算的最终审批权未让渡 → 合法托管；
    • 任一项让渡 → 即向"出租出借办学许可证"滑动，合同无效风险高。

  2. 托管范围是否合理：

    • "全学段 + 全环节（教学+行政+财务+人事+招生）+ 资质移交" = 100% 越界；
    • "部分学段 + 教学管理 + 核心权保留" = 安全区（参考北京怀柔昂立语言培训学校案 (2015) 朝民(商)初10089号）。

  3. 财务是否规范透明：

    • 所有学费、住宿费等办学收入必须进学校对公账户；
    • 受托方私收费用、私设账外户 = 直接违约 + 可能触发合同无效。

3. 任务三：政策边界

3.1 核心法规条款逐条核实

法规 条款 原文要点（核实版） 政策含义
《民办教育促进法》2018 第三次修正版（2016 年第二次修正，2016 年起施行分类管理） 第十九条 "民办学校的举办者可以自主选择设立非营利性或者营利性民办学校。但是，不得设立实施义务教育的营利性民办学校。" 高中/中职段允许营利性；义务教育段只允许非营利性
同上 第五十条 "人民政府委托民办学校承担义务教育任务，应当按照委托协议拨付相应的教育经费。" 民办学校承担义务教育须由政府购买，禁止变相收费
《民办教育促进法实施条例》国务院令 741 号（2021-09-01 施行） 第十三条（最关键）第四款 "任何社会组织和个人不得通过兼并收购、协议控制等方式控制实施义务教育的民办学校、实施学前教育的非营利性民办学校。" 协议控制禁止范围仅限义务教育 + 非营利学前教育；高中/中职/非义务段不在禁令内
同上 第十三条第一、二款 同时举办或实际控制多所民办学校的，应具备相应资金/人员/组织能力；提供教材/课程/技术支持应符合国家规定并建立质量标准 集团化办学的合规门槛：质量标准 + 保障机制
同上 第十三条第三款 "不得改变所举办或者实际控制的非营利性民办学校的性质，直接或者间接取得办学收益" 非营利性学校不得变相牟利（针对多校举办者）
同上 第四十五条 "实施义务教育的民办学校不得与利益关联方进行交易。其他民办学校与利益关联方进行交易的，应当遵循公开、公平、公允的原则，合理定价、规范决策，不得损害国家利益、学校利益和师生权益。" 民办学校应建立利益关联方交易的信息披露制度；有关部门按年度对关联交易进行审查 关联交易禁令只对义务教育民办校；高中/中职关联交易需公开+公允+年度审查——这是高中段整校托管商业化的核心法律口子
同上 第十二条 举办者变更"不得涉及学校的法人财产，也不得影响学校发展，不得损害师生权益"；可"根据其依法享有的合法权益与继任举办者协议约定变更收益" 变更收益合规通道：明示、协议、不涉法人财产
同上 第七条 "实施义务教育的公办学校不得举办或者参与举办民办学校，也不得转为民办学校。其他公办学校不得举办或者参与举办营利性民办学校。" "公办学校举办或者参与举办民办学校，不得仅以品牌输出方式参与办学" 公办校仅以品牌输出方式参与办学被禁——意味着托管方想"用公办品牌"只能与公办校主体协议而非挂靠品牌
同上 第五十八条 "县级人民政府根据本行政区域实施学前教育、义务教育或者其他公共教育服务的需要，可以与民办学校签订协议，以购买服务等方式，委托其承担相应教育任务。" "其他公共教育服务"含高中阶段，政府购买/委托管理的政策口子
同上 第六十二条（法律责任） 举办者及实控人"伪造、变造、买卖、出租、出借办学许可证的"——1–5 年禁入，情节特别严重永久禁入 "出租出借办学许可证"是法律责任核心条款，与司法判例直接挂钩
同上 第六十四条 对学校决策机构负责人、校长及直接责任人予以警告；情节严重 1–5 年禁入；多校举办者疏于管理造成恶劣影响，拒不整改 1–5 年不得举办新校，情节严重 10 年不得举办新校 集团化管理不合规的连带罚则

3.2 学段差异：为什么高中段整校托管相对可行

维度 义务教育段（小学/初中） 高中/中职段
营利性 禁止设立营利性民办校（民促法 §19） 允许营利性民办校，可登记为企业法人、按公司法分配结余
协议控制/兼并收购 禁止（实施条例 §13 第四款） 不禁止——社会资本可通过协议控制、并购方式举办运营
关联交易 禁止与利益关联方交易（实施条例 §45） 允许但需公开、公平、公允、年度审查（实施条例 §45 第二款）
招生 审批机关辖区内、不得提前、不得组织考试（实施条例 §31） 设区市内为主，符合条件可跨区域（实施条例 §31）；招生自主权大
收费 省级政府可制定最高限价（实施条例 §42）；非营利性受严格管控 营利性自主定价、市场调节（实施条例 §44）；非营利性参照公办
政策导向 持续压降占比、推进政府购买学位（5 年压降 650 万人） 仍在增长，2021→2025 校数+995 所、在校生+150 万人

结论：高中/中职段是唯一同时满足"营利性合法 + 协议控制合法 + 关联交易合法 + 招生相对自主 + 收费市场化"五个条件的学段——这是初高中段整校托管商业逻辑相对可行的政策根基。

3.3 公办高中能否被委托管理？

可以，但路径特殊：

  1. 政策依据：

    • 实施条例 §58："县级人民政府……可以与民办学校签订协议，以购买服务等方式，委托其承担相应教育任务"——但此条主要授权的是委托给民办学校而非"民办机构管理公办校"；
    • 教育部等九部门 2021-12《"十四五"县域普通高中发展提升行动计划》——政策语境明确支持"县中托管/帮扶"；
    • 未找到全国层面专门规范"民办机构托管公办高中"的统一规范性文件（数据缺口：待补查各省的实施细则）。

  2. 实践案例（独立核验·地方党报/官网）：

    地区 公办校 受托方 模式要点 信源

    云南玉龙县 玉龙一中（"国有民办"） 云南民族大学基础教育集团 20 年托管期；政府年付管理费 400 万+前三年启动 300 万/年+人才经费 20 万/人·年 二手·界面新闻调查报道

  3. 公办托管的实践形态：

    • "国有民办"模式（玉龙一中）：资产属国有，由民办集团运营管理；法律地位模糊——李春光（浙江省发展民办教育研究院副院长）观点："我国学校只有公立和民办两种性质，不存在国有民办形式"；熊丙奇（21 世纪教育研究院副院长）观点："国有民办是公办引入社会资金的新探索，但应公办归公办、民办归民办"。
    • "政府购买服务 + 派驻管理"模式（屯昌/连平）：政府付费 + 派驻校长与团队；核心控制权仍在政府方，规避实施条例 §62 "出租出借许可证"风险。

  4. 失败案例（警示）：

    • 福州闽侯二中委托案（2019 年起）：受托方"福州至一教育管理有限责任公司"无办学资格，两年高考成绩大幅下滑（2020 年本一上线 25 人 vs 委托前 56–74 人），引发学生家长投诉，福州市教育局指其"与法规相悖"（一手·福建长安网报道）。
    • 启示：无办学/教育服务资格的纯商业公司做整校托管，即使签的是"管理咨询协议"，仍被认定为违规；公办托管必须由有基础教育运营经验的主体承担。

3.4 司法实践：合同无效的边界

委托管理合同 = 出租出借办学许可证 = 合同无效，自始无效；已收费用退还 + 违法所得没收；情节严重的责任人 1–5 年禁入；构成犯罪的，追究刑事责任。

裁判规则提炼（实务口径）：

  1. 合法托管三件套：(a) 举办者保留对办学许可证/印章/法定代表人/对公账户/年度预算的最终权；(b) 受托方仅负责部分教学/管理环节，未接管全部办学资质；(c) 学费归集在学校对公账户，受托方收管理费/服务费，不直接收取学费。
  2. 非法托管触发线：(a) "全托管"+ 资质移交 = 100% 越界；(b) 一方以另一方名义招生、收费、发证 = 越界；(c) 受托方独立设账、私收费用 = 越界。
  3. 司法趋势：从"无效即驳回全部诉求"演化为部分诉求可酌情支持（如芳华案：补偿资产增值部分；安徽案：全额驳回）——裁判尺度因地区/法官而异，签订协议时务必在合同中明确风险分配条款。

4. 任务四：生意成立条件假设清单（待验证）

框架："教学能交付 · 经营能持续 · 能力能复制" 方法论：每条假设均标注"待验证"状态及建议验证路径，供 M2–M7 逐一核验。

# 假设 验证框架 状态 建议验证路径
H1 收费主体必须是营利性法人（高中/中职）才能合法收费并向举办者分配利润 教学能交付 / 经营能持续 待验证 M2 查头部托管公司主体性质（营利/非营利）、工商登记、年报收入分项
H2 地方政府或举办者愿意实质放权——至少让渡教学/人事/财务中的两项日常运营权 教学能交付 待验证 M3 看连平/屯昌/玉龙三个公办托管案例的合同结构（菜单式 vs 全权式）
H3 托管方掌握可迁移的教研与课程产品（教材、教案、考核题库、师训体系） 能力能复制 待验证 M4 拆解天立"六立一达"、海亮"英才培养工程"、衡水教研体系的迁移成本
H4 能批量供给校长与骨干教师（受托方自有"校长池""名师池"） 能力能复制 待验证 M4 看头部企业师资人数 + 培养体系；衡水/海亮/天立均披露师资储备规模
H5 单校收入能覆盖派驻团队成本（人头费 + 管理费 + 平台摊销 + 销售费用） 经营能持续 待验证 M5 测算：单校年学费收入（民办高中约 1.5–3 万/人 × 在校生 1000–3000 人 = 1,500–9,000 万/年）vs 派驻团队成本（5–15 人 × 30–50 万/人·年 = 150–750 万/年 + 总部摊销）
H6 回款有保障——不依赖学费归集（学费归集到学校账上，托管方收的是"管理费/服务费"，与学校办学风险隔离） 经营能持续 待验证 M2/M5 核查受托方收入确认方式：是按托管费（稳定）还是学费分成（与学校经营挂钩）
H7 不触碰义务教育段（初中/小学）——只做高中或中职 政策合规 已部分验证 民促法 §19 + 实施条例 §13/§45；M2 在企业筛选时严卡学段
H8 回款方为非关联方交易合规通道（高中段关联交易需公开+公允+年度审查） 政策合规 已部分验证 实施条例 §45 + 关联交易信息披露制度；M2 在企业筛选时核查年报披露的关联交易
H9 地方政府愿意为托管付费（公办托管路径）或允许营利性民办高中市场化收费（民办托管路径） 经营能持续 待验证 M3 公办托管案例：长治/屯昌/连平/玉龙的政府付费方式（年付/项目付/人才经费付）
H10 能规避"变相出租出借办学许可证"——四权不实质让渡 政策合规 已验证 司法判例（§3.4）：举办者保留办学许可证/印章/法定代表/对公账户/年度预算审批权
H11 生源结构可承接多元升学需求（高考/强基/艺考/留学/复读），不依赖单一高考升学率 教学能交付 待验证 M4 看托管学校的升学结果结构（参考天立、海亮、博实乐等多元化设计）
H12 品牌/课程可定价（特许经营或课程授权可单独收费，不依赖整校交付） 能力能复制 待验证 M4 看是否存在"轻资产输出"业务（只卖课程/品牌/督导，无人员派驻）；参考天立 FY2023 托管收入 2% 占比、衡水早期加盟模式

7. 数据缺口与存疑点

7.1 必须补查的项目

# 缺口 影响 建议补查路径
G1 2024/2025 年公办普通高中总数（=全国普高 − 民办普高） 估算"政府购买服务"潜在池底数 教育部公报"普通高中 1.58 万所"含完全中学+十二年一贯制；需结合各省教育厅的"分市州/分县"统计公报，未找到完整公开数据
G2 民办初中校数单列（2024/2025 年公报合并统计为"民办义务教育阶段"） 估算民义教内部初中池 教育部公报未单列；未找到公开数据——禁止编造；M5 可在分析"为什么初中段不被托管"时用【估算】注明逻辑
G3 2024/2025 年全国"县中"总数 估算县中托管池 教育部"县中提升计划"语境下未单列；未找到公开数据；估算逻辑见 §2.2
G4 司法判例全文（中国裁判文书网） 核验二手报道的案件事实与裁判理由 部分案件（如安徽中专案、怀柔昂立案）仅见二手报道；建议 M3 在"风险"模块用裁判文书网 + 当事人名称穿透核验
G5 "国有民办"模式的中央层面合法性意见 公办托管路径的法律风险敞口 21 世纪教育研究院、教科院专家观点对立（熊丙奇 vs 李春光），但未找到全国统一规范性文件专门定义"国有民办"
G6 托管费行业基准比例（占学费比例、固定年费、混合模式） 测算单校经济模型 公开案例的托管费数据零散（玉龙一中 400 万+300 万启动+20 万/人·年；长治公办案例未披露具体金额；民办内部托管几乎无公开数据）；未找到行业基准——需 M5 通过头部企业年报 + 调研访谈补全
G7 "协议控制"在高中段的合规细节（实操中如何界定"协议控制"与"管理输出"的边界） 高中段托管合同结构设计 民促法实施条例 §13 第四款的"协议控制"针对义务教育段；高中段无此禁令，但司法实践中可能类推适用——未找到明确的"高中段协议控制边界"司法解释
G8 民促法第三次修正后的最新修法动向（2024–2026） 政策窗口期判断 检索到学前教育法、民办高中设置标准征求意见稿等地方文件，但未找到全国人大层面"民促法"再次修订草案——当前适用的是 2018 第三次修正版 + 2021 实施条例

7.2 存疑但暂用【估算】处理的事项

# 存疑 估算逻辑 风险等级
Q1 公办高中总数 全国普高 1.58–1.61 万所 ×（1 − 民办占比 30%）≈ 1.10 万所 中（口径说明即可）
Q2 公办县中占比 参照"县中提升计划"政策语境与基层教学论文中"县中约占公办高中 50–60%"的估算 中（需在 M2 用教育部基础教育司或教科院数据二次核验）
Q3 民办普高学费基准 综合杭州民办普高评测（1.9–2.3 万/学期）+ 桂平/普宁等县级民办高中招生信息 + 国信天立研报（"3 万均价，年增 5%"） 低（区间值可用）
Q4 派驻团队成本基准 头部企业年薪 25–50 万（昆明树兰公开承诺）+ 国信研报"人均年薪 30–40 万" 中（依赖岗位结构）

7.3 明确剔除的来源（降权 / 不引用）
