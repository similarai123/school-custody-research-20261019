二、正文：逐家分析

（一）云南文投教育管理（集团）有限公司

1. 背景

  • 成立时间：2021年10月14日
  • 母公司：云南文投集团（云南省属国有文化企业）
  • 注册资本：100万元（2024年8月从6000万元减资至100万元）
  • 法定代表人：邓飞
  • 企业规模：微型（2025年员工6人）
  • 地址：中国（云南）自由贸易试验区昆明片区经开区

2. 受托学校

学校名称 托管起始时间 合同金额 服务期限
巧家县第五高级中学 2022年6月首次中标 598万元/3年（2022-2025） 3年
巧家县第五高级中学 2024年10月续标 598万元/3年 3年
巧家县第五高级中学 2025年11月最新中标 794.55万元/3年 2025.12-2028.8
巧家县第六中学 2024年7月中标 297万元/3年 3年

3. 费用结构（2025年巧家五中项目）

根据巧家县教育体育局2026年预算公开： - 年度托管费：794.55万元 - 其中60%（476.73万元）：用于云南文投教育管理有限公司的工作经费 - 其中40%（317.82万元）：用于项目学校教师绩效奖励（班主任津贴、超课时津贴、绩效奖金等）及招生费用

4. 模式特点

  • 纯服务费模式：不含教职工工资，教师编制身份、人事关系和社会保险关系不变
  • 学校属性不变：公办性质、资产权属性质不变
  • 招生范围：可面向全县招生
  • 管理团队：引入成都优质教育资源，聘请成都市实验外国语学校原副校长杨登文担任校长，从成都引入3名骨干教师

5. 战略合作

2026年1月，与康旅集团下属教投公司签订战略合作框架协议，双方将在教育资源整合、联合办学以及教育服务拓展等方面合作。文投教育在高中教育资源、教育理念、团队运营等方面的优势，与教投公司在高等教育为核心的"教育+培训"业务模式形成互补。

6. 动机分析

  • 区域教育扶贫：巧家县为云南省昭通市下辖县，教育基础薄弱，通过引入外部优质教育资源提升县域高中教学质量
  • 国企社会责任：云南文投集团作为省属国企，服务区域教育事业发展
  • 轻资产运营：注册资本仅100万元，以教育管理服务输出为主，不涉及重资产投入

（二）珠海华发教育产业投资控股有限公司

1. 背景

  • 成立时间：2014年5月30日
  • 母公司：珠海华发集团有限公司（珠海市属国企，珠海龙头国企）
  • 注册资本：1亿元
  • 法定代表人：何玉冰
  • 旗下学校：17所学校、幼儿园（截至2024年），涵盖学前教育、义务教育、高中教育及综合教育培训
  • 教职员工：1700余名，外籍教师80余名

2. 受托学校——横琴"两校一园"

学校名称 学校性质 托管起始时间
横琴粤澳深度合作区第一中学（横琴一中） 公办初中 2015年7月
横琴粤澳深度合作区第一小学（横琴一小） 公办小学 2015年7月
横琴粤澳深度合作区中心幼儿园 公办幼儿园 2015年7月

3. 合同金额演变

学年 合同金额 采购方式

4. 费用结构（大包模式）

2025-2026学年合同明确，采购人支付费用包括： - 教职工人员费用：受托方派驻教职工的工资、社保等 - 提升办学质量费用：补充办学经费、办园业务经费及专项经费 - 委托管理费：受托方的管理服务费 - 考核奖励费：根据办学质量考核结果支付的奖励

5. 模式特点

  • "全权管理"大包口径：含教职工人员费用，教师由华发教育派驻，采用聘任制与绩效考评
  • 企业化管理模式：引入企业化管理机制，教师培训长效机制
  • 品牌输出：引入容闳教育体系，构建"绿色教育"理念
  • 课程体系：国学教育、国际教育、审美教育、统整教育和自主教育五大课程板块

6. 办学成效

  • 学生总数：从1000余人增长至近3000人，港澳籍学生近百人
  • 教师总数：从100余人增长至近300人
  • 家长满意度：从及格线跃升至常年95%左右
  • 横琴一中：2022年中考12人考入珠海一中，其中屏蔽生2人
  • 横琴一小：教育部STEAM教育课程教学改革试点学校、广东省中小学科学教育示范校
  • 横琴中心幼儿园：广东省首批高质量幼儿园共同体培育对象

7. 动机分析

  • 区域配套：横琴作为国家级新区/粤澳深度合作区，需要优质教育资源吸引人才
  • 人才吸引：解决澳门居民和高端人才子女就学问题，服务大湾区建设
  • 国企担当：华发集团作为珠海龙头国企，承担服务合作区战略部署的责任
  • 品牌延伸：将容闳教育品牌从民办延伸至公办托管领域

（三）成都城投教育投资管理集团有限公司

1. 背景

  • 成立时间：2018年3月
  • 母公司：成都城建投资管理集团有限责任公司（成都市属国企）
  • 注册资本：50亿元
  • 定位：成都市委、市政府为加快国资国企改革发展批准成立的专业化国有投资运营管理公司
  • 工作思路："政府主导、企业主体、商业化逻辑"

2. 托管规模

  • 截至2020年底：累计举办（领办和托管）中小学幼儿园26所，提供优质学位2万余个
  • 截至2021年10月：累计举办（领办、托管）中小学、幼儿园（托育中心）31所，提供学位2.6万个

3. 主要品牌与托管案例

品牌/学校 类型 模式
领川外国语学校 民办 自主办学
菁芙蓉幼儿园 公办 委托管理（与青羊区教育局合作）
城投万汇教育 混合所有制 与四川万汇合资成立
都江堰市领川实验学校 民办 竞拍接手原都江堰南山实验学校
领川江安实验学校 公办 领办（2021年4月）
丹心实验学校 民办 合作管理（更名为领川校名）

4. 模式特点

  • 投建管营一体化：国有教育资源综合运营商
  • 品牌矩阵：培育"领川"、"菁芙蓉"、"城投万汇"等"蓉字号"教育品牌
  • 产业链延伸：带动教育培训、研学游学、在线教育、团餐配送、校服供应等衍生服务
  • 国企员工身份：签约教职员工享有国企员工身份和待遇

5. 国资与民企合作案例——城投万汇教育

  • 合作方：四川万汇文化投资有限公司（民企）
  • 成立时间：2020年6月
  • 模式：国企（城投）+民企（万汇）+国际资源（芬兰教育专家团队）
  • 特点："三位一体"新型教育模式，国企实力+民企机制+国际理念
  • 成果：都江堰万汇学校（K12，芬兰教育方式首次完整落地国内）

6. 动机分析

  • 服务城市战略：助力成都教育现代化、建设教育强市
  • 服务民生需求：缓解基础教育学位供给不足
  • 片区开发配套：通过片区开发收益支持学校建设（参与火车站片区、北城新区、高铁片区等建设）
  • 国企社会责任：办人民满意的教育，建设家门口的好学校

（四）北京金融街教育投资有限公司

1. 背景

  • 成立时间：2016年9月19日
  • 母公司：金融街集团（北京市西城区属国企，中国500强）

2. 托管案例——秦皇岛市第二中学

  • 合作时间：2018年12月
  • 模式："租赁+托管"
  • 内容：以"金融街秦皇岛高中"为平台，将秦皇岛市第二中学委托金融街高中运营，实行一体化管理
  • 学校性质：公办性质不变，仍满足对口施教区范围内适龄生源正常接受义务教育
  • 特色定位：倾向于办成艺术及体育特色学校，契合秦皇岛滨海运动城市形象

3. 其他布局

  • 广东惠州：巽寮湾分校及幼儿园
  • 浙江绍兴：金融街杭州湾学校
  • 品牌："正泽"、"润泽"、"惠泽"基础教育品牌

4. 模式特点

  • 跨区域托管：从北京到秦皇岛，服务京津冀协同发展
  • 租赁+托管：结合资产租赁与学校托管
  • 教育家办学：引入知名校长和教育专家团队

（六）青岛城投集团

1. 背景

  • 青岛市属国企，青岛市首批国有资本投资运营公司试点企业
  • 资产总额超4400亿元（截至2025年末）

  • 片区：青钢片区（青岛市李沧区，占地约2439亩）
  • 模式：城投集团片区开发+名校托管配套

  • 建设青岛五十八中北校区（36班寄宿制高中）

4. 模式特点

  • 片区开发驱动：教育配套服务于低效片区开发，提升区域价值
  • "配套先行"理念：通过优质教育资源导入提升片区配套水平和开发热度
  • 政企校合作：市教育局、城投集团、李沧区政府、青岛五十八中四方合作

  • "双轨制"师资：政府编制教师+集团聘任骨干教师（编制外引进63名优秀教师）
  • 政企校协同：政府（基础保障）、集团（资源注入+难题协调）、学校（教学实施）

4. 动机分析

  • 回馈当地：魏桥创业集团发轫于滨州，回馈父老乡亲
  • 人才战略：解决"工业重镇"沦为"教育洼地"和"人才荒地"的问题，留住人才
  • 企业责任：响应国家振兴县域高中战略

（十）东投教育（江西）

1. 背景

  • 江西南昌教育企业
  • 与地方国有城投公司合作

2. 合作模式

  • 混合所有制：地方政府批准，优质公办学校与东投教育共同举办公办学校冠名的民办学校
  • 公办学校以品牌、师资等无形资产占股
  • 东投教育出资取得教育出让用地、规划建校，以出资占股
  • 或由当地国有城投公司取得教育用地，东投教育出资建设、运营，双方按出资比例持股
  • 公办托管：地方政府教育局将公办学校委托给东投教育集团管理
  • 学校公办性质不变、国有资产属性不变、教师身份编制不变、收费标准不变

三、模式对比：大包模式 vs 纯服务费模式

对比维度 大包模式（华发教育） 纯服务费模式（云南文投）
代表企业 珠海华发教育 云南文投教育
费用构成 教职工人员费用+办学质量费用+委托管理费+考核奖励费 工作经费+教师绩效奖励+招生费用
教职工归属 受托方派驻，聘任制 原学校编制不变，人事关系不变
合同金额 约1亿元/学年（3所学校） 约265万元/年/校（巧家五中）
管理深度 全权管理，全面接管 教育教学委托管理服务
品牌输出 容闳教育体系 引入成都七中等外部资源
适用场景 新建区/开发区，教育基础薄弱，需整体提升 县域学校，需引入外部优质管理
财政压力 较高（含人员费用） 较低（仅服务费）
受托方责任 全面负责办学质量 负责教育教学管理服务

两种模式的共同特点： - 学校公办性质不变 - 资产权属性质不变 - 接受教育行政部门监督 - 以提升办学质量为目标

四、对商业教育集团竞合关系研判

（一）国资身份的优势

优势维度 具体表现
拿地拿单便利 城投集团参与片区开发，可直接配套建设学校；政府采购中，国资背景增加信任度
财政信任 同为体制内单位，财政资金支付更有保障，回款风险低
政策对接 更易获得政府政策支持，参与政府教育规划制定
资源整合 可整合国企内部资源（资金、建设、物业等）支持学校发展
品牌信誉 国企背景提升家长和社会的信任度
长期稳定性 资金实力雄厚，办学稳定性、持续性强

（二）与商业教育集团的关系

1. 竞争关系

  • 托管市场竞争：在公办学校托管市场，国资教育公司与商业教育集团（如海亮、天立、长水）存在直接竞争
  • 品牌竞争：双方都在打造教育品牌，争夺优质生源和师资
  • 区域扩张竞争：都在向教育薄弱地区扩张，获取托管项目

2. 合作关系

合作模式 典型案例 合作内容
国资+民企合资 成都城投+四川万汇=城投万汇教育 国企实力+民企机制+国际资源
国资+商业集团托管 济南城建+蓝城+绿城育华 国资拿地建设，商业集团输出管理
国资引入名校 青岛城投引入青岛五十八中 城投建校，名校托管
国资与民企合作办学 云南景东县国资公司+海亮教育 国资公司签约，海亮交付
城投+名校+政府 长沙城发+雅礼洋湖实验中学 城投投资，名校管理，政府支持

3. 竞合关系研判

  • 短期竞争：在单个托管项目招标中，国资与商业教育集团可能竞争
  • 长期合作：更多呈现合作态势，国资擅长拿地和资金，商业集团擅长教育运营
  • 模式互补：国资大包模式适合新建区整体配套，商业集团轻资产模式适合单校托管
  • 混合所有制趋势：城投万汇模式可能成为主流，国企民企优势互补

（三）市场进入建议

对于商业教育集团而言： 1. 差异化定位：避开国资大包模式的优势区域（新建区/开发区），聚焦县域学校和单校托管 2. 合作共赢：主动寻求与地方国资合作，参与国资拿单后的交付环节 3. 轻资产输出：发挥教育专业优势，以品牌、管理、课程输出为主 4. 区域选择：重点关注国资教育公司尚未覆盖的省份和地区

五、数据缺口

缺口类别 具体内容 原因分析
完整托管学校清单 各地方国资教育公司受托管理学校的完整名单 部分公司官网信息不完整，政府采购信息分散
财务数据 各公司托管业务的收入、利润、成本结构 非上市公司，财务数据不公开
合同细节 托管合同的具体条款、考核指标、退出机制 合同内容通常不公开
办学成效数据 托管学校的教学质量提升数据、学生成绩对比 涉及教育评价，数据敏感
员工数据 各公司托管业务板块的专职员工数量 企业用工信息不公开
扩张计划 各公司未来托管业务发展规划 企业战略信息，公开渠道有限
竞争格局 同一地区国资与商业教育集团的竞争情况 缺乏系统性市场调研
政策影响 地方政府对国资托管的支持政策细节 政策文件分散，需逐地检索

建议补充调研方向： 1. 逐省检索省级政府采购网，搜索"委托管理""托管""教育服务"等关键词 2. 查阅各地国资委官网，了解下属教育板块布局 3. 访谈地方教育局，了解国资托管的实际运作情况 4. 收集更多托管学校的办学成效数据
